# Repository recheck, 3 October 2026

Version 1.0.1 fixes two publication portability gaps: check_geometry.py previously expected unpublished image paths, and the acquisition/strict-profile utilities executed work during import. Geometry now uses native image dimensions read from the original 1,627 images and published alongside their opaque IDs. The acquisition and strict-profile utilities have guarded entrypoints and --help support; the downloader also supports --verify-only. Analysis, native-predictor and external-evaluation scripts support --help.

Verification covers every manifest file's SHA-256, JSON parsing, all 37 NPZ archives and unchanged original prediction/matching arrays, all Python sources, four readable plot PDFs, citation metadata and workflow structure. Every Python module is imported in the full pinned environment. All applicable command entrypoints are exercised with --help. The numeric checker recomputes 37 AP trials, nine timing summaries and 1,050 external records. Geometry checks all 1,627 images with zero mismatches. The full environment passes eight unit tests, including the Windows checkpoint-lock test; lightweight CI runs seven policy/portability tests on Linux and Windows.

Analysis is executed against an isolated copy of the published records and its entire summary compared with the published analysis. External summary functions are recomputed from all clip records. The downloader verifies all 350 actual local AIRTLab video Git blob hashes. Archive extraction and pixel fingerprints are checked using temporary fixtures. Actual object and behavior checkpoints are loaded and tested on real input, once each with square and rectangular FP32 processing. These smoke checks are separate from the published scientific measurements.

The historical full GPU configuration grid, all original timing trials and all external inference trials are not rerun in this repository check. Raw-inference scripts require the original data, checkpoints, full inference dependencies and the CUDA configuration described in REPRODUCIBILITY.md. Those source artifacts are not included in the public repository. A smoke test and checksum check do not guarantee arbitrary inputs, hardware or future dependency versions will work.

Saved scientific metrics and original experimental inputs remain unchanged. The machine-readable local verification is summarized in repository_verification.json. GitHub Actions independently checks the published release on Linux and Windows.
