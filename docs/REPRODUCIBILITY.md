# Reproduction

Use the CPU-only checker in the README for published numerical results. Predictions and original matched true-positive/target arrays are retained; `evaluation_order` freezes the NumPy 1.26.4 confidence ordering actually used in the original evaluation, including ties. This prevents platform-dependent sorting from changing AP. It does not change predictions or target matches.

Full inference: create a separate working directory with the original object_detection/best.pt, behavior_detection/best.pt, merged_object_detection.zip and Violent Behavior Detection.v1i.yolov11.zip, plus Integrated Code/test_videos/*.mp4. Copy study scripts and protocol/manifest files into work/deployment_study under that directory, without copying published results or success markers. Install requirements-inference.txt in a separate environment (the original CUDA runtime was cu124). Set VIOLENCE_STUDY_ROOT to the absolute working-directory path. Run bootstrap_inputs.py --workspace-root PATH, then run_study.py phases prepare, validation, cost, select, test and profile. Native predictor checks and strict profiling use their respective scripts. Read the saved protocols before rerunning, including the timing boundaries, frozen settings, scene-cluster resampling and strict comparison block.

External acquisition uses the pinned AIRTLab revision in external_manifest.json and Git blob checks from external_tree.json. Run download_external.py and evaluate_external.py. Downloading external media is not necessary for the numerical checker. Source imagery and checkpoints must be obtained through a permissible author/source access route. Published numeric records cannot recreate pixels or substitute for new independent validation.

Runtime originally used Python 3.12.3, NumPy 1.26.4, PyTorch 2.6.0+cu124, Ultralytics 8.3.116, OpenCV 4.11.0 and four CPU threads. The saved protocols define all inference settings. CI checks numeric reproduction and policy constraints; it does not repeat GPU inference.
